# Rykantų laiko mašina

Rykantų paveldas nuo 1619 m. iki šių dienų: archyvų dokumentai ir skenai, tekstai, gyventojų balsai iš tinklalaidės „Rykantų pašto laiškai“ ir renginiai.

Rykantų pašto, Piliečių mokslo asociacijos, VILNIUS TECH ir Participio projektas.

Svetainė yra lietuvių ir lenkų kalbomis: kalbą keičia mygtukas PL/LT viršuje, o lenkišką versiją galima atverti ir nuoroda su `?lang=pl`.

## Failai

- `index.html` yra svetainė, kurią rodo GitHub Pages.
- `page.html` yra puslapio šaltinis. Pakeitus jį, paleiskite `python3 build.py`, ir `index.html` bus atnaujintas.
- `data/` yra svetainės duomenų kopijos CSV formatu: klimatas, gyventojai, biblioteka, eismas, organizacijos, kalbos ir tautybės.
- `img/` yra archyvų skenai iš epaveldas.lt (per Europeana). Kiekvieno skeno licencija nurodyta puslapyje prie įrašo.

## Savas domenas

Nusipirkus domeną, į šį aplanką įdėkite failą `CNAME` su domeno vardu (pvz. `laikomasina.lt`), o domeno DNS nukreipkite į GitHub Pages pagal GitHub instrukciją „Managing a custom domain for your GitHub Pages site“.
